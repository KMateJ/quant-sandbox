Multi-step trees and backward induction

Lesson 7 of 17 · 1 min read

A single up-or-down move is too crude to describe a stock over months. This lesson chains many one-step models into a tree and prices an option by applying the formula from "Risk-neutral probabilities" at every node, starting at maturity and working back to today. It also uses the Δt\sqrt{\Delta t}Δt​ scaling from "Random walks and Brownian motion" and continuous discounting from "Interest, compounding and discounting".

Splitting the time to maturity

Divide the time to maturity TTT into nnn equal steps of length

Δt=Tn.\Delta t = \frac{T}{n}.Δt=nT​.

In each step the stock is multiplied by uuu or by ddd, independently of earlier steps. The risk-free bond now grows continuously, so over one step it is multiplied by erΔte^{r\Delta t}erΔt rather than by (1+r)(1+r)(1+r). Each step is a copy of the one-step model with the growth factor 1+r1+r1+r replaced by erΔte^{r\Delta t}erΔt, so the no-arbitrage condition becomes d<erΔt<ud < e^{r\Delta t} < ud<erΔt<u, and the risk-neutral probability of an up move is

q=erΔt−du−d.q = \frac{e^{r\Delta t} - d}{u - d}.q=u−derΔt−d​.

The assumptions are the same as before: no dividends, fractional trading, no transaction costs, borrowing and lending at rrr.

The recombining tree

An up move followed by a down move gives S0udS_0udS0​ud, and a down move followed by an up move gives S0duS_0duS0​du, the same number. Paths that contain the same number of up moves end at the same node. Such a tree is called recombining. After iii steps there are only i+1i+1i+1 distinct prices,

Si,j=S0 uj d i−j,j=0,1,…,i,S_{i,j} = S_0\,u^{j}\,d^{\,i-j}, \qquad j = 0, 1, \dots, i,Si,j​=S0​ujdi−j,j=0,1,…,i,

where jjj counts the up moves. The whole tree has (n+1)(n+2)/2(n+1)(n+2)/2(n+1)(n+2)/2 nodes, while the number of paths is 2n2^n2n. For n=100n = 100n=100 that is 5151 nodes instead of about 1.3⋅10301.3 \cdot 10^{30}1.3⋅1030 paths, which is what makes trees practical.

Choosing uuu and ddd

The factors uuu and ddd should make the tree's stock behave like a stock with annual volatility σ\sigmaσ. The Cox–Ross–Rubinstein (CRR) choice is

u=eσΔt,d=1u=e−σΔt.u = e^{\sigma\sqrt{\Delta t}}, \qquad d = \frac{1}{u} = e^{-\sigma\sqrt{\Delta t}}.u=eσΔt​,d=u1​=e−σΔt​.

Each step changes the log price by ±σΔt\pm\sigma\sqrt{\Delta t}±σΔt​. This is the scaled coin-flip walk from "Random walks and Brownian motion": over nnn steps the variance of the log price change is close to n σ2Δt=σ2Tn\,\sigma^2\Delta t = \sigma^2 Tnσ2Δt=σ2T, which matches the square-root-of-time rule. Because d=1/ud = 1/ud=1/u, an up move and a down move cancel, so the tree is centred on S0S_0S0​ in log terms.

Backward induction

At maturity the option value at each node is its payoff. For a call, Cn,j=(Sn,j−K)+C_{n,j} = (S_{n,j} - K)^+Cn,j​=(Sn,j​−K)+. One step earlier, each node together with its two successors is a one-step model, so its value is the discounted risk-neutral average of the two successor values:

Ci,j=e−rΔt[q Ci+1,j+1+(1−q) Ci+1,j].C_{i,j} = e^{-r\Delta t}\big[q\,C_{i+1,j+1} + (1-q)\,C_{i+1,j}\big].Ci,j​=e−rΔt[qCi+1,j+1​+(1−q)Ci+1,j​].

Repeating this step by step back to the root gives the price C0=C0,0C_0 = C_{0,0}C0​=C0,0​. At each node the replicating portfolio of "The one-step binomial model" still exists, with Δi,j=(Ci+1,j+1−Ci+1,j)/(Si+1,j+1−Si+1,j)\Delta_{i,j} = (C_{i+1,j+1} - C_{i+1,j})/(S_{i+1,j+1} - S_{i+1,j})Δi,j​=(Ci+1,j+1​−Ci+1,j​)/(Si+1,j+1​−Si+1,j​), so the price is the cost of a strategy that is rebalanced at every step.

Backward induction. Set the values at maturity equal to the payoff, then move back one step at a time, replacing each node by e−rΔte^{-r\Delta t}e−rΔt times the qqq-weighted average of its two successors. The value at the root is the arbitrage-free price.

The distribution of the terminal price

Under Q\mathbb{Q}Q each step is an independent up move with probability qqq, so the number of up moves jjj by maturity has a binomial distribution. The probability of ending at node jjj is the number of paths to it times the probability of each path:

Q(ST=S0ujd n−j)=(nj) qj(1−q)n−j.\mathbb{Q}(S_T = S_0u^jd^{\,n-j}) = \binom{n}{j}\,q^j(1-q)^{n-j}.Q(ST​=S0​ujdn−j)=(jn​)qj(1−q)n−j.

Backward induction for a European option therefore gives the same result as a single discounted expectation over the terminal nodes:

C0=e−rT∑j=0n(nj) qj(1−q)n−j (S0ujd n−j−K)+.C_0 = e^{-rT}\sum_{j=0}^{n}\binom{n}{j}\,q^j(1-q)^{n-j}\,\big(S_0u^jd^{\,n-j} - K\big)^+.C0​=e−rTj=0∑n​(jn​)qj(1−q)n−j(S0​ujdn−j−K)+.

As nnn grows, the binomial distribution of jjj approaches a normal distribution, so ln⁡ST\ln S_TlnST​ becomes normally distributed. This is the log-normal model behind Black–Scholes.

Convergence to the Black–Scholes price

The figure plots the CRR call price against the number of steps nnn from 1 to 150, with S0=100S_0 = 100S0​=100, r=5%r = 5\%r=5% and T=1T = 1T=1, and the Black–Scholes price as a horizontal line. With K=100K = 100K=100 and σ=20%\sigma = 20\%σ=20% the tree gives 12.16 for n=1n = 1n=1, 9.54 for n=2n = 2n=2, 10.25 for n=10n = 10n=10 and 10.43 for n=100n = 100n=100, against 10.45. The approach is not smooth: the price zigzags between even and odd nnn, because the terminal nodes shift relative to the strike as nnn changes, and the payoff has a kink at KKK. Move KKK and σ\sigmaσ and note that the size of the zigzag changes, while the curve always settles on the reference line.

American options

An American option can be exercised at any node. Backward induction handles this with one change: at each node take the larger of the exercise value and the continuation value given by the formula above. For a call on a stock without dividends early exercise is never optimal, so its price equals the European one. For an American put it can be optimal, and the tree is the standard way to price it.

Summary

  • A multi-step tree splits TTT into nnn steps of length Δt=T/n\Delta t = T/nΔt=T/n; the bond grows by erΔte^{r\Delta t}erΔt per step and q=(erΔt−d)/(u−d)q = (e^{r\Delta t} - d)/(u-d)q=(erΔt−d)/(u−d).
  • The CRR choice u=eσΔtu = e^{\sigma\sqrt{\Delta t}}u=eσΔt​, d=1/ud = 1/ud=1/u gives a recombining tree whose log-price variance over TTT is about σ2T\sigma^2 Tσ2T.
  • Backward induction applies the one-step pricing formula at every node, from maturity back to today.
  • The number of up moves is binomially distributed under Q\mathbb{Q}Q, and the tree price converges, with oscillation, to the Black–Scholes price as nnn grows.
