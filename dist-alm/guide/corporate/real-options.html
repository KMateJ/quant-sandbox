Real options: the value of flexibility

Lesson 10 of 10 · 1 min read

The lessons "Net present value and internal rate of return" and "Discounted cash flow valuation" valued a project as if its plan were fixed today. Real managers can wait, expand, scale down or stop as information arrives. This lesson values that flexibility with the binomial tree from "Multi-step trees and backward induction" and the early-exercise logic from "American options and early exercise".

Flexibility in investment decisions

The static NPV rule compares the present value VVV of a project's cash flows with the investment III and accepts when V−I>0V - I > 0V−I>0. It treats the decision as now or never: invest today on the current plan, or drop the project for good. Most real projects are not like that. A firm holding a licence or a plot of land can usually delay the investment, expand capacity if demand turns out strong, abandon the project and sell the assets if it goes badly, or switch inputs or outputs. Each of these is a right without an obligation, so each has the payoff shape of an option. Such options on real assets are called real options.

Mapping a project to an option

Take the right to invest in a project. Exercising it means paying III and receiving a project worth VVV, so the payoff is (V−I)+(V - I)^+(V−I)+, the payoff of a call. The pieces translate as follows:

  • Underlying: the present value VVV of the project's cash flows, the quantity a DCF valuation produces.
  • Strike: the investment cost III.
  • Maturity TTT: how long the opportunity stays open (a licence period, a patent life, a lease on land).
  • Volatility σ\sigmaσ: the uncertainty of VVV, how much the project's value can change per year.
  • Dividend yield δ\deltaδ: the cash flows the project would already pay while the firm is waiting, as a yield on VVV. They are lost by waiting.

Since the firm can invest at any date up to TTT, the option to delay is an American call on VVV with strike III.

When waiting pays

With δ=0\delta = 0δ=0 the argument from "American options and early exercise" carries over. Investing at time ttt gives Vt−IV_t - IVt​−I, while keeping the right is worth at least Vt−Ie−r(T−t)V_t - Ie^{-r(T-t)}Vt​−Ie−r(T−t), which is larger: waiting delays the payment of III and keeps the protection against a fall in VVV. So with no forgone cash flows it is never optimal to invest before TTT.

With δ>0\delta > 0δ>0 waiting has a cost. A project already running pays roughly δV\delta VδV per year, and a firm that waits receives none of it. When the project is deep in the money, a fall below III is unlikely, so the protection is worth little, while the forgone cash flow δV\delta VδV is large because VVV is large. Then investing at once beats waiting, exactly as a large dividend can make early exercise of an American call optimal.

The option to expand

Suppose that by paying an extra IeI_eIe​ the firm can scale the project up by a fraction xxx, turning VVV into (1+x)V(1 + x)V(1+x)V. At a date when the option can be used, the project with the option is worth max⁡(V, (1+x)V−Ie)=V+(xV−Ie)+\max\big(V,\,(1+x)V - I_e\big) = V + (xV - I_e)^+max(V,(1+x)V−Ie​)=V+(xV−Ie​)+. The expansion right is therefore a call on xVxVxV with strike IeI_eIe​, valued on the same tree by adding this term at the decision nodes. It pays off exactly in the states where demand turned out strong.

The option to abandon

If the firm can stop the project and sell its assets for a salvage value AAA, then at each decision date the project is worth max⁡(V,A)=V+(A−V)+\max(V, A) = V + (A - V)^+max(V,A)=V+(A−V)+. The abandonment right is a put on VVV with strike AAA. It limits the downside: in bad states the firm walks away with AAA instead of keeping a project worth less. On the tree, each node takes the larger of the continuation value and AAA.

Limits of the analogy

Option pricing rests on replication: the option's payoff can be copied by trading the underlying, which pins the price down. A project's value VVV is not traded, so no such portfolio exists in general. The risk-neutral valuation used above is then an approximation, justified if some traded asset (a commodity, a listed firm in the same business) moves closely with VVV. The inputs are also harder to estimate than for a stock option: σ\sigmaσ and δ\deltaδ have to be inferred from forecasts, and competitors may take the opportunity away before TTT.

Summary

  • Static NPV assumes a now-or-never decision; the rights to delay, expand, abandon or switch are options on the project value VVV.
  • The option to delay is an American call on VVV with strike III; the forgone cash-flow yield δ\deltaδ plays the role of a dividend yield.
  • With δ=0\delta = 0δ=0 investing early is never optimal; with δ>0\delta > 0δ>0 investing at once can be optimal when the project is deep in the money.
  • On a binomial tree with q=(e(r−δ)Δt−d)/(u−d)q = (e^{(r-\delta)\Delta t} - d)/(u - d)q=(e(r−δ)Δt−d)/(u−d), each node takes the maximum of investing now and waiting; the root value is the expanded NPV.
  • Expanding is a call and abandoning is a put on VVV; since VVV is not traded, the valuation is an approximation.
